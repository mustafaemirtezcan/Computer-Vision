# Computer Vision

Computer vision assignments as Jupyter notebooks. Datasets are not included.

- **PA1 - Traffic Sign Detection:** Hough transform and RANSAC circle detectors implemented from scratch and evaluated on a GTSDB subset. Hough reached an F1 score of 0.30.
- **PA2 - Single-Object Tracking:** ResNet18-based bounding-box regressor used as a closed-loop tracker. The full submission is available on [Google Drive](https://drive.google.com/file/d/1O7QZFf4Adny6GeKEYU6TGrLZfrBrQ1cb/view?usp=sharing).
