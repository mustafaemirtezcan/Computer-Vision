# 🧑‍💻 Computer Vision

Teaching computers to find and follow objects 👁️.

## 🚦 PA1 - Traffic Sign Detection

Finds round traffic signs in street photos with two classic methods built from scratch, the Hough Transform and RANSAC, and compares how well they do. Hough came out far ahead.

## 🎯 PA2 - Object Tracking

A ResNet-based tracker that follows an object through a video, frame by frame. It stays locked on in steady scenes but struggles with fast motion and crowds.
